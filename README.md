# MdStock

A stock management web application developed for a real business use case at Marrakech Distribution, designed to optimize inventory tracking and improve operational efficiency.

## Description

MdStock is a full-stack web application built to solve real-world challenges in stock and logistics management.

The system replaces inefficient manual or legacy processes by providing a centralized platform to manage inventory, track product movements, and automate ordering and reporting workflows.

The application enables real-time stock monitoring, improves traceability, and supports better decision-making for the business.

## Problem

The company faced several issues:

- Inaccurate stock tracking  
- Inefficient ordering processes  
- Lack of product traceability  
- Poor reporting and data visibility  
- Complex and non-user-friendly system  

## Solution

MdStock introduces a complete system to:

- Track stock in real time  
- Manage products, categories, suppliers, and warehouses  
- Automate purchase orders and stock movements
- Generate and manage invoices  
- Provide dashboards and statistics  

## Features

- Inventory and stock management  
- Product, category, and supplier management  
- Warehouse (depot) management  
- Purchase order and stock movement management  
- Invoice generation and printing  
- User authentication and role-based access  
- Activity history tracking  
- Dashboard with statistics and charts  

## Tech Stack

- Symfony (Backend - MVC architecture)  
- MySQL (Database)  
- HTML, CSS, JavaScript  
- jQuery & AJAX (dynamic updates)
